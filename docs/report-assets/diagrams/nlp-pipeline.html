Explainable incident classification

A compact, inspectable NLP pipeline combines TF-IDF features and a linear SVM with deterministic keyword guardrails, gazetteer location extraction and extractive summaries.
01 · Input

Title and body from public notices, advisories or mapped construction records.

05 · Output

Structured record

Category, location, summary and classification provenance are stored for inspection.

categorylocationsummarymethod
Named location extractionLongest-match gazetteer over Mumbai localities and corridors; avoids invented locations and retains approximate precision.
Extractive summarySentence scoring based on content-word frequency; deterministic and bounded to a short readable summary.
Transparent categoriesAccident · Road Closure · Construction · Traffic Diversion · Public Event · Parking Restriction · Other.
ExplainabilityMethod and confidence are retained with the record; no black-box transformer is required for the core pipeline.
