Idempotent collectionStable fingerprints and external IDs prevent duplicate inserts. Re-collected changed records are updates, counted separately.
Observable failuresSource failures, rejected rows and duplicate counts are stored in collection_logs. Empty or failed runs are not replaced with fabricated data.
